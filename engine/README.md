# Pulsefold: The Ghost Cycle
## Separate experiment · first playable slice

The orbital habitat's fictional metabolism depends on timed chamber slots. A conflicting move returns CONFLICT and leaves the ledger right, but the planted bug quietly moves a cycle in the chamber index. A green marker and a red result can coexist.

### Open the preview

Import `viewer/project.godot` into Godot 4 and run the main scene, or run:

    godot --path viewer --rendering-method mobile --rendering-driver vulkan

Use **STEP** twice to reach the conflicting move. **TOGGLE FAULT** switches between the correct and planted-bug trace and rewinds to step 1. **BACK** and **RESET** do not recompute or change state. If Vulkan is unavailable, try `--rendering-method gl_compatibility` without the Vulkan flag. The viewer is a replay console, not a full game or a second scheduler.

### Build and run the Rust simulation

Requires Cargo and stable Rust 1.65 or newer. No crate dependencies.

    cargo test --offline
    cargo run --offline -- assays/ghost.assay
    cargo run --offline -- assays/ghost.assay --stale-index

Normal exit codes: 0 when all per-operation invariants hold, 1 when any fails, and 2 for malformed input. A valid CONFLICT can coexist with exit 0: the expected rejection must not mutate state. A mutant exit 1 is the expected negative control.

To feed freshly generated outputs to the same console:

    cargo build --offline
    target/debug/pulsefold assays/ghost.assay > /tmp/pulsefold-control.tsv
    target/debug/pulsefold assays/ghost.assay --stale-index > /tmp/pulsefold-mutant.tsv
    godot --path viewer -- --control=/tmp/pulsefold-control.tsv --mutant=/tmp/pulsefold-mutant.tsv

The mutant command's exit 1 is intentional. `./verify.sh` codifies all assertions, checks byte equality with the packaged traces, and validates those traces with Godot if available.

### What this slice proves, and what it doesn't

- **Simulation contract:** two chambers; integer ticks; half-open intervals. Maintain a canonical ordered ledger and an independent chamber index. Compare indexed availability to a direct scan in the two scene windows and require exact index/ledger consistency and no state change on rejection.
- **Replay contract:** one operation per line in a minimal Assay syntax. The runner emits stable tab-separated rows; renderer side effects never affect the scheduler. No randomized generator, turbulence, batch booking, or persistence in this slice.
- **Study boundary:** EXACT is scripted and only illustrates signal/outcome separation. No live agent runs, canary efficacy claims, TLA+ validation, or changes to the existing Canary Lab repository or cohorts. A future live experiment needs a preregistered protocol with recorded markers alongside independently scored behavior.
- **Status:** Godot 4 loaded and validated both packaged example traces headless. Those traces were assembled from the scenario and oracle expectations, not generated by a verified Rust run. The workspace lacked Cargo/rustc and a GPU-backed display, so Rust compilation, live Vulkan rendering, and performance were not verified here. Do not read the packaged traces as measured experiment results.

Design references: [TigerBeetle's simulator game](https://tigerbeetle.com/blog/2023-07-11-we-put-a-distributed-database-in-the-browser/) and [Godot's renderers](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html). For a later all-Rust renderer, prefer [wgpu](https://github.com/gfx-rs/wgpu) over raw Vulkan for this scale. Keep the simulator independent of the graphics layer in either case.
