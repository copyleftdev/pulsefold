# Pulsefold: The Ghost Cycle
## Separate experiment · first playable slice

The orbital habitat's fictional metabolism depends on timed chamber slots. A conflicting move returns CONFLICT and leaves the ledger right, but the planted bug quietly moves a cycle in the chamber index. A green marker and a red result can coexist.

### Open the preview

Import `viewer/project.godot` into Godot 4 and run the main scene, or run:

    godot --path viewer --rendering-method mobile --rendering-driver vulkan

Use **STEP** to reach turn 3's conflicting move (step 9). **TOGGLE FAULT** switches between the correct and planted-bug trace and rewinds to step 1. **BACK** and **RESET** do not recompute or change state. If Vulkan is unavailable, try `--rendering-method gl_compatibility` without the Vulkan flag. The viewer is a replay console, not a full game or a second scheduler.

### Build and run the Rust simulation

Requires Cargo and stable Rust 1.65 or newer. No crate dependencies.

    cargo test --offline
    cargo run --offline -- trace sessions/control.session     # exit 0
    cargo run --offline -- trace sessions/ghost.session       # exit 1: the planted bug
    cargo run --offline -- summary sessions/ghost.session

Seeded simulation, with shrinking to a replayable assay ([guide](../docs/SIMULATION.md)):

    cargo run --offline -- sim --variant stale-index --seed 1 --runs 1000 --ops 64 --shrink-to /tmp/pf
    cargo run --offline -- trace /tmp/pf/seed-2.session

Planted-bug catalog, with detection rates and Wilson intervals:

    cargo run --release --offline -- catalog --runs 1000 --ops 64

Concurrent clients under a seeded scheduler, checked for linearizability ([guide](../docs/RACES.md)):

    cargo run --offline -- race --variant check-then-act --runs 1000 --shrink-to /tmp/pf
    cargo run --offline -- race --replay /tmp/pf/race-seed-28.race

Exit codes: 0 when every row matches the reference, 1 when any row fails, 2 for usage or input errors; `sim` also exits 3 when nothing failed but a sometimes-property never fired; `catalog` exits 1 unless every bug is found and no control is flagged. A correct `CONFLICT` passes: the reference rejects the same move and nothing observable changes.

To feed freshly generated traces to the native console:

    cargo build --offline
    target/debug/pulsefold trace sessions/control.session > /tmp/pulsefold-control.tsv
    target/debug/pulsefold trace sessions/ghost.session > /tmp/pulsefold-mutant.tsv
    godot --path viewer -- --control=/tmp/pulsefold-control.tsv --mutant=/tmp/pulsefold-mutant.tsv

`./verify.sh` codifies all assertions; see [the replay contract](../docs/REPLAY.md).

### What this slice proves, and what it doesn't

- **Simulation contract:** two chambers; integer ticks; half-open intervals. Each turn's implementation runs beside a separate reference; results, booking lists and availability in each operation's original and attempted windows must match.
- **Replay contract:** one operation per line in a minimal Assay syntax, replayed per turn of a session. The runner emits stable trace v2 rows; renderer side effects never affect the scheduler. No randomized generator, turbulence, batch booking, or persistence in this slice.
- **Study boundary:** responses are scripted; EXACT only illustrates signal/outcome separation. No live agent runs, canary efficacy claims, TLA+ validation, or changes to the existing Canary Lab repository or cohorts. A future live experiment needs a preregistered protocol with recorded markers alongside independently scored behavior.
- **Status:** `verify.sh` passed on rustc 1.99.0 with Godot 4.7.2 headless; the packaged traces are generated by the runner. Live Vulkan rendering and performance are not verified. Do not read the packaged traces as measured experiment results.

Design references: [TigerBeetle's simulator game](https://tigerbeetle.com/blog/2023-07-11-we-put-a-distributed-database-in-the-browser/) and [Godot's renderers](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html). For a later all-Rust renderer, prefer [wgpu](https://github.com/gfx-rs/wgpu) over raw Vulkan for this scale. Keep the simulator independent of the graphics layer in either case.
